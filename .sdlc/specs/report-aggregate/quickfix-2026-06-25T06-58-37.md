# Quickfix: Restate all deprecated EARS dialect in canonical form

**Date**: 2026-06-25
**Feature**: report-aggregate  **Key**: REPORT-AGGREGATE
**Trigger**: `sdlc-validate.py` emits 13 EARS dialect warnings against `report-aggregate/spec.md`

## Behaviour Change Summary

No behaviour change. The spec was authored before the project adopted canonical EARS. All 13 requirements use
deprecated patterns (`ALWAYS SHALL`, `WHERE … THEN SHALL`, `UNLESS … THEN SHALL`) that carry identical
semantics to their canonical counterparts. This quickfix restates each requirement in canonical EARS so the
validator runs clean; the implementation and tests are already correct.

## Requirements Delta

*Use canonical EARS (WHEN / WHILE / WHERE / IF…THEN / ubiquitous SHALL).*

*(none)*
