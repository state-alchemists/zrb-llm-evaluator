## 0.1.9 — 2026-05-25

### Added
- `--env-prefix` CLI option and `env_prefix` field on `ExperimentConfig` (default `"ZRB"`), enabling white-label zrb forks to use a different environment variable prefix for `{prefix}_LLM_HISTORY_DIR` and `{prefix}_LLM_JOURNAL_DIR`
- Per-trial LLM journal isolation: a `notes/` directory is created alongside `workdir/` and `history/` inside each trial cell, and `{env_prefix}_LLM_JOURNAL_DIR` is set so that journal/activity-log entries written by the LLM never leak into the user's real `~/.zrb/llm-notes/`
- New requirements documented: REQ-030 (preserve `Experiment.id`/`started_at` across resumed invocations), REQ-031 (wipe existing cell directory before retry), REQ-032 (`list` subcommand), REQ-033 (`report` subcommand), REQ-034 (aggregate validation errors into single `ValueError`), REQ-043 (deterministic report timestamps from experiment timestamps)
- New unit tests: UT-046 (journal env var is set and is a sibling of history dir), UT-047 (each trial gets its own isolated journal dir), UT-044 (real zrb `💸` format parsing with Audio Input/Output exclusion), UT-045 (last-line-only cost parsing when multiple summary lines appear), UT-A026 (whole-file byte equality across re-renders), UT-A027 (generated timestamp derived from experiment timestamps)
- New drift-report and quickfix specification documents

### Changed
- Cost parser regex rewritten to match zrb's actual `💸` usage summary format (`💸 (Requests: … | Tool Calls: … | Total: T) Input: I | Audio Input: … | Output: O | Audio Output: … | Cache Read: C | …`) instead of the old `Total tokens:` format; negative lookbehinds prevent `Audio Input:` / `Audio Output:` from bleeding into the `input`/`output` groups
- Cost parser now uses `finditer` and takes the **last** match when multiple `💸` lines are present, avoiding double-counting of cumulative per-turn totals
- `ZRB_LLM_HISTORY_DIR` env var is now set via the configurable `{env_prefix}_LLM_HISTORY_DIR` (default `ZRB_LLM_HISTORY_DIR`)
- Spec documents updated: ADR-3, experiment-runner design/requirements, report-aggregate design/requirements, and entity dictionary to reflect journal isolation, env prefix, and timeout process-group kill behavior
- NFR-002 wording relaxed from O(T) to O(T log T) to account for per-section sorting

### Fixed
- Token counting: regex updated to match the actual zrb `💸` output format; multi-line handling fixed to use the last cumulative summary line instead of the first, preventing double-counting across turns
- Drifting documentation: ADR-3 and spec documents synchronized with the current implementation (journal isolation, configurable env prefix, process-group timeout kill)
