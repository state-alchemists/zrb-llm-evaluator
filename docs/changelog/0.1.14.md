## 0.1.14 — 2026-06-25

### Added
- SDLC conventions document (`.sdlc/CONVENTIONS.md`) defining artifact paths, EARS dialect, ID/traceability scheme, and approval tiers.
- Consolidated feature specs under `.sdlc/specs/`: `evaluator/spec.md`, `experiment-runner/spec.md`, `report-aggregate/spec.md`.
- SDLC validation tool (`.sdlc/tools/sdlc-validate.py`) — deterministic validator for traceability, EARS syntax, and ID hygiene.
- CLI version detection: `_get_cli_version()` queries the configured CLI binary for its version string; the version is stored in `ExperimentConfig.cli_version` and displayed in the report header.
- Leaderboard section in Markdown reports — ranked by pass rate, EXCELLENT count, and average score.
- Input token, output token, and score tracking per model in aggregate report buckets.
- Input Tokens and Output Tokens columns in the By Model table.
- Quickfix and drift-report documents for recent spec updates.

### Changed
- Migrated all steering docs (`docs/`), specs (`specs/`), and tests (`tests/`) into the `.sdlc/` directory tree.
- Updated all source file headers to use the keyed SDLC tag scheme (e.g., `EXPERIMENT-RUNNER:REQ-001` instead of bare `REQ-001`).
- Updated `AGENTS.md` and `README.md` to reference the new `.sdlc/` artifact paths.
- Updated ADR-7, ADR-8, and ADR-9 with minor corrections.

### Fixed
- CLI version now correctly displayed in reports (the `_get_cli_version` helper was added to the `run` command).

### Removed
- Old standalone spec files: `specs/evaluator/design.md`, `specs/experiment-runner/design.md`, `specs/experiment-runner/requirements.md`, `specs/report-aggregate/design.md`, `specs/report-aggregate/requirements.md` — superseded by the consolidated `.sdlc/specs/` specs.
