## 0.1.8 — 2026-05-23

### Added
- Per-trial LLM journal isolation: the runner now sets `ZRB_LLM_JOURNAL_DIR` to a per-cell `llm-notes/` directory (sibling of `workdir/` and `history/`), so that zrb's journal notes are isolated per trial. ([REQ-016](https://github.com/state-alchemists/zrb-llm-evaluator))
- New test cases for cost-parser: `test_cost_summary_parsed_real_zrb_format` (UT-044), `test_cost_summary_uses_last_line_when_multiple` (UT-045), and `test_cost_summary_partial_zrb_line_returns_zero`.
- New test cases for journal isolation: `test_journal_env_var_set` (UT-046) and `test_llm_notes_isolated_per_trial` (UT-047).

### Changed
- Updated `REQ-016` in requirements spec to mandate `ZRB_LLM_JOURNAL_DIR` alongside `ZRB_LLM_HISTORY_DIR`.
- Updated `REQ-019` in requirements spec to describe the real zrb `💸` format and the "last line only" rule.

### Fixed
- Token counting now matches the actual zrb `💸` usage summary format (with `Audio Input`/`Audio Output` fields) instead of the obsolete `Total tokens:` format. Negative lookbehinds prevent `Audio Input`/`Audio Output` values from bleeding into the `input`/`output` groups.
- When multiple `💸` summary lines appear in stdout, only the last line is used — previously the first match was taken, which could undercount cumulative totals.
