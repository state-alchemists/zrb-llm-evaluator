## 0.1.2 — 2026-05-20

### Added
- **LLM subprocess isolation via nested workdir (ADR-7):** each trial now runs with `cwd` set to a dedicated `workdir/` directory nested inside the per-trial cell directory, keeping evaluation artifacts (`stdout.log`, `history/`, `validator.py`, `instruction.txt`) invisible to the LLM under test.
- New requirements: `US-008`, `AC-008`, `AC-009`, `REQ-020`–`REQ-024` defining the isolation contract.
- Per-trial filesystem layout documented in the design spec: `{cell_dir}/workdir/` (LLM-visible) with `stdout.log` and `history/` as siblings (LLM-invisible).
- Stderr progress logging: the CLI now configures a `logging.StreamHandler` for the `zrb_llm_evaluator` package, and `WorkSteward` logs `START`/`DONE` messages per trial with status, duration, and progress counters.
- `--yolo true` flag passed to the `zrb chat` subprocess invocation.
- Direct-to-disk streaming of subprocess stdout/stderr (via file handle) so partial output survives a timeout — previously buffered PIPE bytes were lost on `proc.kill()`.
- Test suite for workdir isolation: `UT-027` (cwd ends in `/workdir`), `UT-028` (artifacts outside workdir), `UT-029` (empty workdir created when no source), `UT-030` (staged files land in nested workdir), `UT-031` (metadata files never staged), and `IT-005` (end-to-end isolation assertion).

### Changed
- **Subprocess `cwd`:** from `{cell_dir}` to `{cell_dir}/workdir/` — the nested directory is created before every trial and the test case's `workdir/` contents are staged into it.
- **Loader `workdir` resolution:** no longer falls back to the test-case directory itself when `workdir/` is absent; always points to `{test_case_dir}/workdir` (which may not exist, in which case the runner stages nothing).
- **Validator `output_dir`:** changed from `cell_dir` to `nested_workdir` so the validator inspects only the files the LLM saw.
- **Subprocess I/O model:** switched from `asyncio.subprocess.PIPE` + `proc.communicate()` to `stdout=log_file` + `stderr=asyncio.subprocess.STDOUT` + `proc.wait()`, with timeout handling refactored accordingly.
- **Model name validation regex:** hyphen (`-`) is now allowed in the provider part of the model string (e.g. `openai:gpt-4o` was already valid; now `my-provider:model` works).
- **Test mocks:** updated `test_runner.py` to match the new file-based I/O pattern — mock subprocesses write output into the log file handle instead of returning bytes from `communicate()`.
- **Entity dictionary:** `workdir` field description updated to reflect that the path may not exist on disk (treated as empty source).
- **Architecture docs:** ADR-7 added to the ADR table.
- **Design spec:** atomicity section updated to note that unused cell directories (including nested `workdir/`) are removed and recreated on retry.
- **Requirements spec:** new `REQ-020`–`REQ-024` added under Always, Event-Driven, and Action-Driven sections.
- **Test plan:** new unit tests `UT-027`–`UT-031` and integration test `IT-005` added; validation coverage matrix updated.
- **Problem brief:** `US-008`, `AC-008`, `AC-009` added for workdir isolation.
- **Version:** bumped from `0.1.1` to `0.1.2`.

### Fixed
- Subprocess stdout/stderr no longer lost on timeout — streaming directly to disk preserves partial output that was previously discarded when `proc.kill()` terminated the process before `communicate()` returned buffered data.

### Removed
- Fallback behaviour where a test case without a `workdir/` subdirectory would have its entire directory (including `validator.py` and `instruction.txt`) used as the subprocess `cwd` — this previously exposed evaluation metadata to the LLM.
