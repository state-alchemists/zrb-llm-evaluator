## 0.1.7 — 2026-05-23

### Added
- Aggregate sections to the Markdown report: **Overall Status**, **By Model**, **By Test Case**, **Grid** (model × test-case), and **Failing / Timeout Trials** — emitted between the header lines and the existing `## Summary` table (US-010, AC-013 through AC-017)
- ADR-9 documenting the aggregate sections design decision
- Specs (`requirements.md` and `design.md`) for the report-aggregate feature
- Unit test suite (`test_reporter_aggregate.py`, 893 lines) covering all aggregate requirements and non-functional requirements
- Integration test (`test_integration_aggregate.py`) verifying aggregate values match the per-trial Summary table
- Golden test files for aggregate report output (`report_summary_and_details.md`, `results.json`)
- Test plan for the report-aggregate feature
- User story US-010 and acceptance criteria AC-013 through AC-017 to the problem brief
- Validation rule that `TrialResult.duration` is always populated (even for `TIMEOUT`/`ERROR` trials), safe for use in the **By Model** average duration computation

### Changed
- `MarkdownReporter` component description in architecture.md updated to reflect aggregate pre-section responsibility
- Entity dictionary description of `Report.markdown_path` updated to mention aggregate sections
- Architecture decision log updated to reference ADR-9
- Version bumped from 0.1.6 to 0.1.7
