## 0.1.15 — 2026-07-04

### Added
- `CliAdapter` protocol (`protocols.py`) and `--cli-template` option — every CLI-specific decision (subprocess argv, env vars, usage/tool-call parsing) is now resolved from a single adapter instead of being hardcoded in the runner.
- Built-in adapters: `zrb` (default, preserves prior behavior exactly), `claude-code` (non-interactive stream-json mode), and `opencode` (non-interactive JSON/NDJSON run mode).
- Custom adapters via dotted import path (e.g. `--cli-template mypkg.MyAdapter`), resolved and validated before any trial begins.
- `--honor-verification-marker` flag — opt-in to let a `VERIFICATION_RESULT:` line in the agent's own stdout override the validator verdict (off by default).
- CLI cmd template support (`cli_adapters.py`).

### Changed
- README.md documents `--cli-template`, `--honor-verification-marker`, and the adapter mechanism.
